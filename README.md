# KIIP 4단계 구술시험 플래시카드 - 짱(Trang)

베트남 유학생 짱(Trang)을 위한 KIIP 사회통합프로그램 4단계 중급2 구술시험 플래시카드.

🌐 **데모:** https://sdjcoding.github.io/kiip-trang-flashcard/

## 콘텐츠

총 77문항 (2개 유튜브 채널 통합):

| 채널 | 출처 | 구성 | 문항 수 |
|------|------|------|---------|
| 토픽스쿨 (TopikSchool) | 한국어와 한국문화 중급2 구술작문연습 | 1과~16과 | 47개 (구술 31, 작문 16) |
| 시대에듀 (SD에듀) | 사회통합프로그램 중간평가 모의고사 | 제1회~제6회 | 30개 |

## 응시자 프로필

- **이름:** 짱 (Trang)
- **국적:** 베트남 (하노이)
- **한국 거주:** 5년 이상
- **신분:** 한국 대학원 경영학 석사 과정 재학 중
- **목표:** 한국 취직 → 영주권(F-5) 취득

## 답변 특징

- 모든 답변 격식체(~습니다) 통일
- KIIP 4단계 중급2 학습 문법 활용 (~느라고, ~을수록, ~곤 했다, ~다시피, ~는 한 등)
- 베트남 문화 비교 사례 포함 (뗏 명절, 반쯩, 아오자이, 하롱베이 등)
- 대학원 생활 사례 반영
